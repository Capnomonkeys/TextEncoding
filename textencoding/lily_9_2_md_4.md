# Punctuation Marks in Code
# ;
>Semicolons are used to end lines of code, essentially the period of the programming world.
> Example:
```css 
body{
    color: blue;
    /*A semicolon ends the line of code. */ 
}
```
# :
>Colons are used in CSS to assign different values to parameters.
```css 
body{
    color: blue;
    /*A colon assigns the color "blue" to the body of text. */    
}
```
# ()
>Parenthesis are used to contain bits of math or code, usually for
> things such as outside variables in functions and instructions for loops.
```js
var add2 = function(number) {
    //Inside the function, the variable "number" is contained
    //within parenthesis.    
    return number + 2;
}
```
# {}
>Curly Braces are used to determine what's part of a function. 
```css 
body{
    color: blue;
}
/* Everything assigned to the body is done within the curly braces. */
```
# =
>Equals Signs can be used to set a variable to a specific value. 
> Generally more common than colons outside of CSS.
```js
var add2 = function(number) {
    //add2 is set to the outcome of this function.
    return number + 2;
}
```
